# Hello World (Blazor)

A simple Hello World web application using Blazor.

## Features

- **Blazor Web App** — Component-based UI built with C# and Razor
- **Server interactivity** — Interactive rendering powered by ASP.NET Core
- **Cross-platform** — Runs on Linux, macOS, and Windows via .NET

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) (10.0 or later)

## Build & Run

```sh
cd hello_blazor
dotnet run --urls http://localhost:5000
```

If the build succeeds, open:

- [http://localhost:5000/](http://localhost:5000/) to see `Hello, world!`

## Stop

Press `Ctrl+C` in the terminal to stop the server.
