# Hello World (.NET Aspire)

A minimal Hello World sample using .NET Aspire.

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) (10.0 or later)
- Aspire templates (`dotnet new install Aspire.ProjectTemplates`)

## Build & Run

```sh
cd hello_aspire
dotnet run --project hello_aspire.AppHost
```

This starts the Aspire AppHost dashboard and local resources for the solution.
